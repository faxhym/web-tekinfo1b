# Kontribusi

1. Diskusikan perubahan besar dengan pemilik repo; gunakan branch terpisah.
2. Pertahankan HTML/CSS/JS tanpa runtime dependency kecuali disepakati.
3. Jangan menambahkan statistik, status akreditasi, fasilitas, atau klaim institusi tanpa URL sumber dan tanggal pemeriksaan.
4. Buka situs tanpa JavaScript; semua konten dan tautan utama harus tetap tersedia.
5. Jalankan `npm ci`, `npm test`, dan `npx prettier --check index.html webtekinfostyle.css script.js tests/site.spec.js playwright.config.js`.
6. Periksa desktop/mobile, keyboard, teks diperbesar dan reduced motion. Sertakan screenshot dan hasil tes dalam PR.
7. Jangan mengubah lisensi upstream atau mengklaim aset sebagai milik sendiri. Konfirmasi hak penggunaan sebelum deploy.

Tidak ada push, deployment, atau PR otomatis dalam deliverable redesign ini.
